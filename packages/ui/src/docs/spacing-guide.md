# Spacing Guide

## 8px Grid System

All spacing values are based on an 8px modular scale.

| Token | Value | Common Usage |
|-------|-------|-------------|
| 0 | 0px | Reset |
| 0.5 | 4px | Micro spacing, icon gaps |
| 1 | 8px | Small padding, button gaps |
| 1.5 | 12px | Input padding, chip spacing |
| 2 | 16px | Standard padding, card padding |
| 2.5 | 20px | Section spacing |
| 3 | 24px | Card padding, form spacing |
| 4 | 32px | Section padding, modal padding |
| 5 | 40px | Page section spacing |
| 6 | 48px | Large section spacing |
| 8 | 64px | Page margins |
| 10 | 80px | Hero section spacing |

## Border Radius

| Token | Value | Usage |
|-------|-------|-------|
| none | 0px | Full-bleed elements |
| xs | 2px | Checkbox, small indicators |
| sm | 4px | Inputs, selects |
| md | 6px | Buttons (default) |
| lg | 8px | Cards, dialogs |
| xl | 12px | Modals, drawers |
| 2xl | 16px | Extra large surfaces |
| full | 9999px | Badges, chips, avatars |

## Layout Max Widths

| Container | Max Width |
|-----------|-----------|
| sm | 768px |
| md | 1024px |
| lg | 1280px (default) |
| xl | 1400px |
| full | 100% |

## Responsive Padding
- Mobile: `px-4` (16px)
- Tablet: `px-6` (24px)
- Desktop: `px-8` (32px)
