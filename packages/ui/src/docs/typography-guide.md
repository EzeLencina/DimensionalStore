## Best Practices
- Use `display-*` tokens for hero sections and page titles
- Use `heading-*` for section headers and card titles
- Use `body-*` for paragraphs and regular content
- Use `caption` for timestamps and auxiliary info
- Use `overline` for labels and category headers
- Never use font sizes outside the scale
