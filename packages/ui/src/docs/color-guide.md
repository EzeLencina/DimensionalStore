## Accessibility Notes
- All color combinations meet WCAG AA contrast ratios
- Text on primary: contrast ratio > 4.5:1
- Text on muted surfaces: contrast ratio > 3:1 for large text
- Focus ring uses `--ring` with 2px offset for visibility
